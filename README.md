## Como iniciar na escola (Node.js 20)

1. Baixe e extraia o ZIP.
2. Abra a pasta `petcare/escola-node20`.
3. Execute `INICIAR_ESCOLA_WINDOWS.bat`.
4. Mantenha a janela preta aberta.
5. No computador, abra http://localhost:3000.

A versão escolar usa armazenamento JSON local, não precisa instalar bibliotecas externas e é compatível com Node.js 20 ou superior.

### Acesso pelo celular

Conecte o celular e o computador à mesma rede Wi-Fi. No computador, execute `ipconfig`, encontre o Endereço IPv4 da rede Wi-Fi e no celular abra `http://IP-DO-COMPUTADOR:3000`. Mantenha o computador ligado e o servidor aberto. Se a rede da escola bloquear a comunicação entre dispositivos, apresente pelo próprio computador.
