PETCARE — DEMONSTRAÇÃO NA ESCOLA
Grupo: Lucas, Gabriel Luan e Leonardo — Turma 3A

COMPATIBILIDADE
Node.js 20 ou superior. Não precisa instalar bibliotecas externas.

INICIAR
1. Abra esta pasta escola-node20.
2. Clique em INICIAR_ESCOLA_WINDOWS.bat ou execute node server.js.
3. Acesse http://localhost:3000.
4. Use contas e dados fictícios.

ARMAZENAMENTO
Esta versão usa JSON local, para funcionar no computador da escola com Node 20.
A versão SQLite é executada em online-sqlite com Node 22.5+ (Node 24 recomendado).
As duas usam a mesma interface e as mesmas regras do servidor.

TESTES
Execute node --test test.js nesta pasta ou npm test na pasta petcare.
