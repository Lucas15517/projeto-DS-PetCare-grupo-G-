# Capturas reais para a banca

Guardar aqui capturas feitas no navegador ou no celular durante a execução real do PetCare.

Checklist sugerido:
1. Tela de login e acesso aos 10 fundamentos.
2. Cadastro e edição de um pet.
3. Lista de serviços e preços.
4. Agendamento concluído.
5. Segunda tentativa no mesmo horário, mostrando conflito HTTP 409.
6. Assistente educativo de cuidados.
7. Aplicativo instalado no celular e consulta offline.

Não inserir dados pessoais, e-mails reais, tokens, senhas ou informações de clientes. Não usar imagens simuladas como se fossem capturas de execução.
